    Histórico de buscas

      Conectar ao GitHub

      Para o botão iniciar a busca daqui mesmo, este navegador precisa de um token do GitHub que só pode rodar o workflow deste repositório. O token fica salvo apenas neste navegador.

      1. Abra a criação do token (já vem com a permissão Actions: Read and write).
      2. Em Repository access, escolha Only select repositories e marque só este repositório.
      3. Clique em Generate token, copie e cole abaixo.
